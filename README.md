# 心型・止念 HeartType Stoic Pause

靜態網頁**模擬器**（無需後端、無需建置）。以 HRV／心跳指紋的視覺語言，搭配斯多葛「停念」，練習食欲調節與體重管理的**選擇**，而不是追逐體重數字。

**線上版本：** https://lion5835.github.io/stoic-pause-simulator/  
（若 404：到 repo Settings → Pages → Source 選 `main`／根目錄並 Save。）

介面為繁體中文（台灣，`zh-Hant-TW`）。桌面會顯示在手機外框裡，手機上全螢幕。所有生理與統計資料皆為瀏覽器內生成的**模擬資料**，畫面會清楚標示。

## 概念

「心型」沿用現場量測原型的 16 型與四軸：

| 軸 | 字母 | 意義 |
|---|---|---|
| 節拍 | L 緩板 / A 快板 | 平均心率偏從容或偏快 |
| 彈性 | F 靈活 / S 穩定 | RMSSD 相對同齡示範常模 |
| 律動 | B 呼吸型 / W 長波型 | SD1/SD2（呼吸性變異 vs 較慢起伏） |
| 沉靜 | Q 速靜 / G 漸靜 | 坐下後多久接近穩定 |

型名：晨湖、竹林、潮汐、山嵐、燈塔、古鐘、河床、雪原、海風、溪流、浪花、雲雀、節拍器、鼓手、列車、星火。

「止念」來自斯多葛控制二分（愛比克泰德《手冊》第 1 節）：

- **在你控制內：** 停下來、呼吸、分辨身體飢餓或情緒飢餓、選擇怎麼吃或先不吃、夜晚誠實回顧。
- **無法完全控制：** 體重數字本身、渴望會不會出現、睡眠與壓力、別人的評價。

產品要練的不是「永遠不餓」，而是渴望出現時，判斷還在自己手上。

## 功能

1. **引導** — 用短頁說明控制二分、一天三個節拍，以及健康資訊聲明。
2. **晨間基線** — 模擬約 90 秒心律：動畫心電圖 + 逐漸成形的 Poincaré 心跳指紋（可加速或略過）。產生今日心型、狀態提示（例如節拍偏快時情緒性進食風險較高），以及愛比克泰德／奧理略／塞內卡的**真實引文**（附出處）。
3. **止念（核心）** — 大按鈕「我想吃東西」→ 兩分鐘引導慢呼吸（吸 4 秒、吐 6 秒）、呼吸圓與模擬 RMSSD 上升 → 反思（飢餓 1–10、情緒標籤）→ 選擇：正念地吃／再等一會兒（2、5、10 或 15 分鐘）／做替代行動，並記錄結果。倒數、夜誌與儀表板會使用所選時長。設定可開示範加速。
4. **塞內卡夜誌** — 今日停念、成功之處、觸發情境、自由書寫、清醒程度評分。
5. **儀表板** — 止念次數與清醒選擇率、7／30 日模擬 HRV 趨勢、觸發長條圖；體重為次要小數值。圖表用 Canvas，無重量級套件。
6. **設定／示範** — 深淺色、加速倍率、記錄體重、植入 30 日示範資料、清除本機資料、語言說明。

資料存在 `localStorage`（鍵名 `ht-stoic-pause-v1`），不上傳。

## 證據與限制（請務必閱讀）

- **這不是醫療器材，也不能診斷或治療。** 心電圖、RMSSD、心率、Poincaré 圖與體重曲線都是模擬。心型切點（例如 70 bpm、同齡第 50 百分位、SD1/SD2 0.5）與常模是示範值，需臨床顧問確認。
- HRV 可反映自律神經的當下狀態，並隨睡眠、壓力、咖啡、運動改變；文獻**不支持**單靠 HRV 數字或「心型」來治療肥胖或飲食疾患。
- 慢呼吸、延遲滿足、分辨情緒性進食，與正念／認知行為取向的研究較接近；效果因人而異，不能替代專業治療。
- 斯多葛引文為通行譯文，原文見 Epictetus *Enchiridion*、Marcus Aurelius *Meditations*、Seneca *Letters* / *De Ira* / *De Brevitate Vitae*。
- 若有進食疾患病史、正在接受相關治療，或出現胸痛、喘不過氣、快要昏倒，請尋求專業或緊急醫療（119）。
